# cp-cli

`cp-cli` is a command line tool that can help you in running your commands.

## Get Started

Pre-requisites:

- Install cpp using brew.
- Fix the bits/stdc++.h library issue in your macbook

Clone this directory to get the code for the tool, and setup an alias.

## Features

- Can run your code.

## User Manual

### Compile

`cp-cli compile {{relative_file_path}}.cpp`

It compiles the file and generates an executable file {{relative_file_path}}.exe

### Execute

`cp-cli execute {{relative_file_path}}.exe`

It executes the compiled file.

### Run

`cp-cli run {{relative_file_path}}.cpp`

It compiles and executes the file.

This is a convenience command.
